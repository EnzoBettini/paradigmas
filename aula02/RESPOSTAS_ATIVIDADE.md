1-A evolucao das linguagens se da em ramificacoes para atender a dominios especificos e nao como uma linha reta onde uma linguagem supera a outra em tudo. Dois fatores sao o surgimento de novos dominios de aplicacao, exigindo recursos que a linguagem original nao tinha sem torna-la obsoleta em seu dominio original, e as mudancas nas metodologias de programacao, que geram novas linguagens baseadas nas anteriores mas focadas em novos paradigmas.

2-Ela e relevante por ser a primeira linguagem de programacao de alto nivel projetada, introduzindo conceitos muito a frente de seu tempo. Tres recursos antecipados foram estruturas de dados avancadas como arranjos e registros, comandos de atribuicao e comandos iterativos. O valor das estruturas de dados avancadas e permitir agrupar dados complexos de forma logica, facilitando a resolucao de problemas matematicos e cientificos que exigem manipulacao de matrizes e vetores.

3-O problema enfrentado por todos era a dificuldade extrema de programar em linguagem de maquina. O Short Code adotou a estrategia de interpretar instrucoes matematicas traduzidas manualmente, o Speedcoding estendeu a arquitetura do hardware via software para interpretar operacoes de ponto flutuante, e os sistemas A da Grace Hopper expandiam pseudocodigos em rotinas de codigo de maquina pre-existentes. Chama-los de compiladores modernos e impreciso porque eles eram essencialmente interpretadores ou expansores de macros, nao realizando analise lexica e sintatica complexa para gerar codigo objeto otimizado de forma autonoma como os compiladores atuais.

4-Na epoca o tempo de processamento dos computadores era carissimo e a memoria muito limitada, entao o codigo precisava ser extremamente eficiente em desempenho. Os programadores desconfiavam que um tradutor automatico geraria um codigo lento e ineficiente comparado ao codigo de maquina feito a mao. O projeto Fortran focou fortemente em gerar um codigo objeto altamente otimizado para superar essa resistencia, provando que o ganho no custo e velocidade de programacao compensava qualquer pequena perda de desempenho da maquina, o que foi essencial para a adocao em massa da linguagem.

5-O Fortran foi criado para o dominio da computacao cientifica e numerica, usando variaveis numericas e matrizes como representacao de dados principal, favorecendo um estilo de computacao imperativo e focado em alta velocidade de processamento. O Lisp surgiu no dominio da inteligencia artificial, utilizando listas encadeadas e atomos para representacao de dados, favorecendo a computacao simbolica e o paradigma de programacao funcional, onde a manipulacao de simbolos e listas e mais importante do que calculos numericos pesados.

16-Perl nasceu para processamento de texto e relatorios usando arrays e hashes e e compilada para codigo intermediario antes de interpretada. JavaScript surgiu para scripts no navegador usando objetos e arrays sendo tradicionalmente interpretada. PHP comecou para scripts no servidor web baseando se fortemente em arrays associativos sendo interpretada. Python surgiu como linguagem de uso geral com listas tuplas e dicionarios sendo compilada para bytecode e depois interpretada. Ruby focou em orientacao a objetos pura para uso geral usando arrays e hashes sendo interpretada. Lua foi feita para ser embarcada e estender aplicacoes usando tabelas como estrutura unica sendo compilada para bytecode e interpretada.

17-A primeira decisao e a inclusao de structs como tipos de valor alocados na pilha diferente de Java onde todo objeto e alocado no heap o que resolve o problema de desempenho e sobrecarga do coletor de lixo para objetos pequenos. A segunda decisao e o uso de delegates em vez de ponteiros de funcao do C++ ou interfaces do Java o que resolve o problema de seguranca dos ponteiros perigosos e a verbosidade extrema das interfaces oferecendo uma forma segura e direta de tratar eventos e referencias de metodos.

18-No XSLT a entrada e um documento XML o processamento ocorre por meio do casamento de padroes com templates e a saida e outro documento XML ou HTML. No JSP a entrada e uma requisicao HTTP o processamento executa codigo Java embutido no arquivo e a saida e um documento HTML gerado dinamicamente para o cliente. Ambas sao hibridas porque misturam no mesmo arquivo texto de marcacao estatico com construcoes de programacao imperativa como lacos e condicionais para manipular dados e gerar conteudo dinamicamente.

19-Fortran do paradigma imperativo influenciou o design de controle de fluxo do Algol imperativo. Algol influenciou o Simula do paradigma orientado a objetos servindo de base sintatica para a primeira criacao de classes. Simula influenciou o Smalltalk orientado a objetos ao inspirar a definicao de orientacao a objetos pura e troca de mensagens. C imperativo influenciou o C++ orientado a objetos adicionando o conceito de classes a sua sintaxe estruturada. C++ influenciou o Java orientado a objetos que limpou a sintaxe herdada e removeu ponteiros diretos para maior seguranca. Lisp do paradigma funcional influenciou o Scheme funcional simplificando a linguagem original e focando em escopo estatico. Prolog do paradigma logico surgiu para computacao baseada em deducao e influenciou linguagens de consulta. Lisp tambem influenciou o ML funcional inspirando a criacao de linguagens funcionais com inferencia de tipos e forte tipagem estatica.

20-Para calculo cientifico a familia imperativa como Fortran ou C e ideal pois historicamente foi construida priorizando velocidade extrema de execucao e manipulacao eficiente de matrizes matematicas. Para regras declarativas a familia logica como Prolog e a escolha certa pois processa fatos e inferencias de forma natural sem exigir passos de fluxo de controle explicito. Para web interativa linguagens de script baseadas em objetos como JavaScript resolvem o problema pois nasceram especificamente para integrar dinamicamente arvore de elementos no navegador. Para firmware restrito linguagens imperativas de baixo nivel como C sao mandatorias pois oferecem controle direto dos enderecos de memoria e acesso cru ao hardware. Um trade off visivel e a escolha entre desempenho extremo da memoria no firmware contra a grande produtividade e abstracao na web interativa. Outro trade off e o controle de execucao onde a familia logica facilita a escrita de regras de negocios mas perde totalmente no controle fino de recursos que o calculo cientifico exige.
